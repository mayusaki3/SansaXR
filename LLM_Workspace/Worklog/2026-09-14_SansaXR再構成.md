## 決定事項

### SXR-DEC-001 SansaXR責務

SansaXRはProjectSansa内でXR runtime / OpenXR / networkingを担当する。
主対象はXR Runtime、World Runtime、Realtime Networking、Session、runtime側のSansaVRM利用、Interaction、Desktop Integration、Engine Integrationとする。

SansaSphereが担当する認証・権利・来歴・検証・経済・ポータル、およびSansaVRMが担当するフォーマット・schema・validator等をSansaXRの正本責務としない。

### SXR-DEC-002 旧実装

developブランチのdocs以外の既存実装は継承を必須とせず、破棄可能とする。
旧docsはProjectSansa再構成前の資料であり、新責務に照らして維持・移管・吸収済み・廃止を判定する。

### SXR-DEC-003 Demo 1

Demo 1は新しいSansaXR Runtimeの最小技術検証とする。
O3DE版とGodot版を同一要件で作成し比較する。

最低検証対象:
- OpenXR
- HMD tracking
- Left/Right controller tracking
- simple 3D world
- multiplayer session
- remote head/hand synchronization
- disconnect/reconnect

### SXR-DEC-004 Engine abstraction

最初から共通Runtime Adapterを実装しない。
まずO3DE native版とGodot native版を実装し、実測結果から共通概念とエンジン固有概念を抽出してSansaXR Core / Engine Adapter境界を設計する。

高頻度のRendering、Physics、Animation、IK等は原則としてエンジン内部に残し、抽象化境界で不要な毎フレーム変換・コピーを発生させない。

### SXR-DEC-005 UGC

UGCの正本をO3DE PrefabまたはGodot Scene等の特定エンジン形式に固定しない。
UGCはSansa側のコンテンツとして管理し、各runtimeで実行可能な形式へ接続する方向で検討する。

Demo比較にはRuntime UGC Pipelineを評価対象として含める。
最低試験候補は、外部GLB等を実行中に取得・ロード・生成し、別クライアントにも対応するオブジェクトを表示することである。

### SXR-DEC-007 Networking二段階比較

Networkingは二段階で比較する。

- Phase A: 各Engine native networkingで最小XR Multiplayerを成立させ、Engine自身の機能性・性能・開発性を評価する。
- Phase B: Common SansaXR Wire Trialを用意し、O3DE/Godotの相互接続とEngine非依存のPlayer State / Session State意味論を評価する。

Phase AとPhase Bの評価結果を混同しない。

## 最新検証結果

- O3DE 26.05.0をDemo 1 baselineとした
- Godot 4.7.2-stableをDemo 1 baselineとした
- Godot 4.7公式XR documentationの推奨に従い、Godot Demo 1はMobile rendererをbaselineとする
- Godot OpenXRでは `XR > OpenXR > Enabled` と `XR > Shaders > Enabled` を有効化し再起動する
- O3DEは26.05.0 Windows installer + Project Managerを構築baselineとする
- O3DEのOpenXR integrationは実インストール環境のGem Catalog/metadataで互換性を確認する
- NetworkingはPhase A native比較とPhase B common wire比較へ分離する
- Runtime UGCのAsset Pipeline/Editor依存度を重点評価する
- Engine Adapterの性能は抽象化の粒度に依存するためnative実装後に境界を決める
- 旧実装削除後のrepository rootが必要最小限の構成になったことを確認済み
- READMEを現在のSansaXR責務とDemo 1作業状態へ更新した
- Demo 1構築手順を目次へ追加済み
